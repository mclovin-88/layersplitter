# Layer Splitter

แยก layer จากไฟล์ .psd / .psb เป็น PNG ทีละไฟล์ แล้วดาวน์โหลดเป็น ZIP — ใช้งานฟรีบนเบราว์เซอร์

- ไฟล์ไม่ถูกอัปโหลดไปที่ไหน ทุกอย่างประมวลผลบนเครื่องผู้ใช้
- เลือก layer ได้, ตั้ง DPI, ตัดขอบใส, เลือกพื้นหลัง
- ชื่อไฟล์ 1.png, 2.png… เรียงจาก layer บนสุดลงล่าง (group กลายเป็นโฟลเดอร์)

ใช้งาน: https://mclovin-88.github.io/layersplitter/

ไลบรารีที่ใช้: [ag-psd](https://github.com/Agamnentzar/ag-psd) (MIT), [JSZip](https://stuk.github.io/jszip/) (MIT/GPLv3)
